# 1bit.kr

> 이 저장소에는 게임이 둘 있다. 현재 주력은 방치형 **[어비스 딜버](idle/README.md)** (`idle/`) 이고,
> 아래는 먼저 만든 레이캐스팅 FPS (`site/`) 다. FPS 의 몬스터 스프라이트를 방치형이 가져다 쓴다.

레이캐스팅 FPS. 정적 파일만으로 동작한다 (빌드 없음, 의존성 없음, 이미지/사운드 에셋 없음).

PC와 모바일 양쪽에서 동작한다. 화면 크기에 맞춰 캔버스가 늘어나고, 손가락이 처음 닿는 순간 터치 조작판이 나타난다.

## 조작 — PC
| 키 | 동작 |
|---|---|
| W A S D | 이동 (전후진 / 좌우 스트레이프) |
| 마우스 | 조준 — 상하좌우 (화면 클릭 시 포인터 잠금) |
| 좌클릭 | 발사 (AK는 누르고 있으면 연사) |
| 1 / 2 | 무기 교체 |
| R | 장전 |
| Esc | 마우스 잠금 해제 |

## 조작 — 모바일
| 동작 | 방법 |
|---|---|
| 이동 | 화면 왼쪽 절반을 누른 채 드래그 (누른 자리가 스틱 중심) |
| 조준 | 화면 오른쪽 절반을 드래그 |
| 발사 | 우하단 발사 버튼 (AK는 누르고 있으면 연사) |
| 장전 / 무기 교체 | 발사 버튼 왼쪽의 작은 버튼 두 개 |
| 다시 시작 | 사망 화면을 탭 |

이동과 조준은 동시에 된다 (멀티터치).

터치일 때는 **에임 보정**이 걸린다. 조준선에서 ±10도 안에 적이 있으면 그쪽으로 부드럽게
끌어 주고, 피격 판정 반경도 1.6배가 된다. 마우스에는 걸지 않는다 — 정밀하게 겨눌 수
있는데 손대면 오히려 방해다.

## 무기
| 키 | 무기 | 탄창 | 예비탄 | 특징 |
|---|---|---|---|---|
| 1 | AK-47 | 30 | 120 | 연사, 탄퍼짐 있음, 발당 위력 낮음 |
| 2 | 리볼버 | 8 | 48 | 단발, 정확, 한 방에 처치 |

탄약과 장전 상태는 무기별로 따로 관리된다.

## 몬스터
스폰은 가중 추첨이며 비율은 **7 : 2 : 1** (잡몹 70%, 중간보스 20%, 보스 10%).

| | 임프 | 파괴자 | 군주 |
|---|---|---|---|
| 비중 | 7 | 2 | 1 |
| 체력 | 3 | 14 | 40 |
| 이동 속도 | 1.35 | 1.05 | 0.85 |
| 공격력 | 8 | 17 | 28 |
| 점수 | 100 | 500 | 1500 |
| 체력바 | 없음 | 표시 | 표시 |
| 구급상자 드롭 | 10% | 45% | 확정 |
| 탄약상자 드롭 | 22% | 65% | 확정 |

## 체력과 보상
플레이어 체력은 100에서 시작하고 HUD 왼쪽 막대로 보인다 (50% 아래 주황, 25% 아래 빨강).

몬스터를 잡으면 그 자리에 보상이 떨어지고, 밟고 지나가면 자동으로 줍는다.

- **구급상자** — 체력 +30 (가득 차 있으면 줍지 않고 남겨 둔다)
- **탄약상자** — AK +45, 리볼버 +12

체력바는 중간보스부터 머리 위에 뜬다. 미니맵에서도 종류별로 색과 크기가 다르다.
스프라이트는 이미지 파일 없이 캔버스 도형으로 그려 굽는다.

## 구성
- `site/engine.js` — 레이캐스팅·충돌·시야·장전·몬스터 표 등 순수 로직 (DOM 의존 없음)
- `site/game.js` — 렌더링, 몬스터 스프라이트, 입력, 게임 루프
- `site/index.html` — 화면과 HUD
- `site/test.js` — 코어 로직 자체 검증

## 로컬 실행
```
cd site && python3 -m http.server 8000
# http://localhost:8000
```

## 테스트
```
node site/test.js   # ok 가 나오면 통과
```

## 배포
`site/` 를 nginx `root` 로 지정하면 끝. 정적 파일이라 런타임이 필요 없다.
