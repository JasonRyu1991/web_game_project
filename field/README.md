# field — 횡스크롤 협력 방치형

`site/`(FPS)·`idle/`(방치형)에 이은 세 번째 클라이언트이자 **정본**이다.
개인 프로젝트의 인프라 명제("WebSocket 세션이 붙은 워크로드를 튕기지 않고 스케일 인")를
증명하기 위한 워크로드로 쓴다. 맵 1개 · 채널 N개 · 채널 1개 = 파드 1개.

## 파일

| 파일 | 역할 |
|---|---|
| `core.js` | 수치·규칙 전부. **DOM 을 모른다.** 채널 파드(Node)가 그대로 `require` 해서 권위 계산을 맡는다 |
| `sprites.js` | 픽셀 스프라이트. 문자 격자 + 팔레트, 오프스크린 캔버스에 구워 캐시 |
| `game.js` | 화면·입력·저장. 여기 계산은 전부 "예측"이며 서버가 붙으면 응답으로 대체된다 |
| `index.html` | 한 화면 레이아웃 (HUD · 장비 · 채널 · 기여도 · 채팅) |
| `test.js` | 코어 검증 16건. `node field/test.js` |

## 규칙

- **레벨** 1~100. 요구치 `100 × lv × 1.045^(lv-1)` — lv1 100, lv2 209, lv30 1만, lv99 74만
- **몬스터 경험치**는 요구치의 **5분의 1 속도**로만 따라 오른다 (`EXP_CATCHUP = 0.2`).
  lv1 에 10 주던 몬스터가 lv2 에 12. 이 값이 1 이면 레벨업 속도가 영원히 그대로고, 0 이면 30 레벨에서 멈춘다
- **몬스터 10종** — 기본(슬라임·쥐·멧돼지·곰) / 레어 lv10↑(유니콘·새스쿼치·좀비) / 유니크 lv20↑(퇴역군인) /
  중간보스 국회의원(채널 100처치 소환, 넥타이 레드·블루 무작위) / 보스 곰돌이 푸(300처치 소환)
- 등장 판정은 **개인이 아니라 채널 최고 레벨** 기준이다. 고렙이 들어오면 저렙도 레어를 같이 본다
- **장비** 무기(공격력) · 투구/갑옷(방어력), 각 1~10등급. 등급당 1.55배 → 10등급이 1등급의 약 46배
- **방어력은 비율 경감**(`raw × 100/(100+def)`). 감산이면 방어력이 공격력을 넘는 순간 무적이 되어 곡선이 무너진다
- **기여도** 넣은 피해 비율로 보상 분배. 한 대라도 때렸으면 최소 5% 보장(막타 독식 방지)
- **조작** 방향키(또는 화면 좌우 패드)로 이동. **5초간 입력이 없으면 자동 사냥**으로 전환
- 공격은 항상 자동. 접촉하면 체력이 깎이고, 사망 시 3초 후 부활(페널티 없음)

## 서버로 옮길 때

`core.js` 는 이미 순수 모듈이라 그대로 `require` 하면 된다. `game.js` 에서 갈아끼울 곳은 두 군데다.

1. `Store.load/save` — localStorage → `fetch`. 인터페이스가 이미 async 라 호출부는 그대로다
2. `state.players` — 지금은 로컬 더미 2명(`ponytail:` 주석). WS 로 채널 멤버를 받아 채우면 된다
3. `chatInput` 의 Enter 핸들러 — 로컬 echo → WS 방송

`/metrics` 로 내보낼 지표는 `state.players.length`(= `active_players`)이고,
`pod-deletion-cost` 에 같은 값을 써넣으면 한산한 채널부터 닫힌다.

## 튜닝 메모

- 곰(atk 20)이 1레벨 유저(최대 체력 74)를 3초 만에 죽여서, 멧돼지 `minLv 3` · 곰 `minLv 6` 게이트를 넣었다.
  스펙상 넷 다 "기본 몬스터"이므로 이 두 줄만 지우면 원안대로 돌아간다 (`core.js` MONSTERS)
- 점프는 넣지 않았다. 지면이 평평해서 쓸 데가 없고, 자동 사냥과도 충돌한다
