# 어비스 딜버

방치형 키우기. 몬스터가 끝없이 나오고 자동으로 싸운다. 정적 파일만으로 동작한다
(빌드 없음, 의존성 없음, 이미지·사운드 에셋 없음). PC와 모바일에서 조작이 같다.

## 구성
- `core.js` — 수치와 규칙 전부. **DOM 을 모른다.** 나중에 서버가 그대로 `require` 해서
  권위 계산을 맡을 수 있도록 순수 함수로만 짰다.
- `game.js` — 화면, 입력, 저장. 몬스터 스프라이트는 `../site/game.js` 의 것을 가져와 쓴다.
- `index.html` — 한 화면 레이아웃
- `test.js` — 코어 로직 검증

## 몬스터
등급 3단계에 생김새 7종. 어떤 게 나올지는 스테이지로 정해지므로 같은 자리에 가면
늘 같은 몬스터가 나온다 (서버가 검증하기도 쉽다).

| 등급 | 생김새 | 체력·보상 배수 |
|---|---|---|
| 잡몹 | 임프 · 슬라임 · 해골 | 1 |
| 정예 | 파괴자 · 골렘 | 3.5 |
| 보스 | 군주 · 용 | 12 |

5 스테이지마다 색조가 돈다. 스프라이트를 새로 그리는 것보다 훨씬 싼 다양화 수법이고
`hue-rotate` 를 걸어 (종류, 색) 조합마다 한 번만 구워 캐시한다. 다만 한 바퀴 다 돌리면
돌 골렘이 초록이 되므로 ±36도로 묶었다.

## 타격과 죽음
- 맞으면 뒤로 밀리고 실루엣이 하얗게 번쩍하며 불꽃이 튄다. 치명타는 더 크게 튄다.
- 죽으면 스프라이트를 7×8 격자로 잘라 조각마다 날려 보낸다. 조각은 회전하며 작아지고,
  연출이 끝나면 다음 몬스터가 나온다.

## 놀이 방법
가만히 둬도 초당 피해만큼 자동으로 깎인다. 화면을 누르면 추가 타격이 들어간다.
몬스터 10마리를 잡으면 다음 스테이지, 매 스테이지 마지막은 중간보스,
5의 배수 스테이지 마지막은 보스다.

## 성장 곡선
체력이 지수로 늘기 때문에 공격력도 지수로 늘어야 한다. 강화 효과를 덧셈으로 두면
2분 만에 벽에 막히므로 `stats()` 는 전부 곱연산이다. 보상 증가율(1.30)을
체력 증가율(1.42)보다 낮게 두어 뒤로 갈수록 느려진다.

시뮬레이션 기준 진행 속도 — 1분 3 · 15분 25 · 1시간 42 · 2시간 50 스테이지.

| 강화 | 효과 | 비용 증가율 |
|---|---|---|
| 공격력 | 단계마다 +8% | 1.16 |
| 공격 속도 | 단계마다 +5% (상한 8회/초) | 1.19 |
| 치명타 | 단계마다 +1% (상한 75%) | 1.22 |
| 행운 | 드롭률 상승 (상한 50%) | 1.25 |

## 장비
슬롯 3개(무기·장갑·부적)에 등급 4종(일반·희귀·영웅·전설). 수치는 퍼센트 보너스라
`power` 100 이면 해당 항목이 두 배가 된다. 지금 낀 것보다 좋은 게 나오면 자동으로 장착된다.

가방에서는 **끼면 실제로 얼마나 세지는지**를 계산해 보여 준다 (`previewEquip`).
"+104%" 같은 수치만으로는 체감이 안 오기 때문에 "끼면 초당 피해 +34%" 로 환산한다.
부적은 피해가 아니라 골드에 붙으므로 따로 표시한다. 등급별 출현 빈도와 주운 층수도 함께 적는다.

강화 탭도 단계당 효과뿐 아니라 지금 수치(공격력 / 초당 타격 횟수 / 치명타율 / 드롭률)를
같이 보여 주고, 상한에 닿으면 그렇다고 알린다.

## 성취 연출
숫자가 커지기만 하는 게임이라 "벌었다"와 "여기까지 왔다"를 눈에 보이게 해 뒀다.

- 처치하면 골드·경험치가 몬스터 자리에서 위쪽 지표로 날아간다. 어디로 들어가는지 보이면
  같은 숫자라도 체감이 다르다.
- 레벨이 오르면 카드가 뜨고 **오른 뒤의 공격력·초당 피해·치명타**를 같이 보여 준다.
- 스테이지를 넘기면 배너, 보스를 잡으면 화면이 번쩍이며 별도 배너가 뜬다.
- 처치 수 이정표(10 · 50 · 200 · 1000 · 5000 · 25000)를 넘으면 칭호 배너가 뜬다.

## 퀘스트
사냥·탐험·수집 세 갈래가 동시에 굴러간다. 한 단계를 끝내면 같은 갈래의 다음 단계가 열리고,
보상은 자동으로 들어가지 않는다 — 직접 받아야 끝냈다는 느낌이 남는다.
받을 게 생기면 탭과 더보기 버튼에 배지가 붙는다.

| 갈래 | 보는 값 | 목표 |
|---|---|---|
| 사냥 | 총 처치 수 | 10 → 50 → 200 → 800 → 3000 → 12000 → 50000 |
| 탐험 | 최고 층수 | 5 → 10 → 18 → 28 → 40 → 55 → 75 |
| 수집 | 주운 장비 수 | 3 → 10 → 25 → 60 → 140 → 300 → 700 |

보상은 그 시점 최고 층수를 기준으로 계산하므로 늦게 깰수록 커진다.

## 더보기 메뉴
상단 우측 ☰ 로 연다. 아래에서 올라오는 시트라 모바일에서 엄지가 닿는다.

- **설정** — 피해 숫자 · 화면 흔들림 켜고 끄기, 진행 초기화(두 번 눌러야 지워진다)
- **기록** — 최고 층수, 총 처치, 주운 장비, 전투력 상세, 획득한 칭호
- **랭킹** — 서버가 붙어야 열린다. 지금은 자리만 잡아 둔 안내 화면
- **정보** — 이 게임에 대한 짧은 설명

## 저장
`localStorage` 에 넣는다. 탭을 숨기거나 닫을 때 즉시 저장하고, 평소에는 묶어서 쓴다.
저장 파일이 낡거나 망가져도 `normalizeSave()` 가 빠진 칸을 메워 게임은 뜬다.

자리를 비운 시간만큼 오프라인 보상을 준다 (접속 중의 50%, 최대 12시간).

## 로컬 실행
```
cd idle && python3 -m http.server 8000
# http://localhost:8000
```

## 테스트
```
node idle/test.js   # ok 가 나오면 통과
```

## 아직 없는 것
로그인과 서버 저장. `core.js` 가 순수 모듈이라 서버로 옮길 때 그대로 들어간다.
